# SIH2026

This repository contains the project workspace for a predictive cyber-defence system.

## AI data and network-state pipeline

The `ai/` workspace is owned by AI Member 1 and is deliberately limited to the technical data pipeline: dataset inspection (only when explicitly authorized), preprocessing and validation, flow/network feature extraction, time windows, network states, technical target preparation, temporal sequences, leakage-safe splits, ML-ready datasets, and their tests and documentation.

Forecasting models and product-facing components are outside this workspace's current scope. See [ai/README.md](ai/README.md) and [ai/AGENTS.md](ai/AGENTS.md).
